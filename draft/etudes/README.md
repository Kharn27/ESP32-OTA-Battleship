# Études et propositions non homologuées

Ce dossier regroupe les **prévisualisations et études héritées** qui ne sont **pas des assets individuels approuvés** :
- `ocean/` : fonds A/B en attente de validation PO ;
- `patrouilleur/` : scènes plein cadre avec mer incrustée, **pas des sprites transparents** ;
- Le sous-marin FLOT-01 **INTACT H/V a reçu le GO artistique PO en PR #97** puis a été transféré dans [`assets/flotte/sous-marin/`](../../assets/flotte/sous-marin/README.md) par [Issue #109](https://github.com/Kharn27/ESP32-OTA-Battleship/issues/109). Les anciens fichiers de preuve sont consultables dans l'historique Git, pas dans `draft/`.

Les originaux et brouillons du PO restent à la racine de `draft/`, inchangés. Aucun fichier de ce dossier ne peut être consommé comme ressource firmware approuvée sans passage explicite vers `assets/manifest.json`.
